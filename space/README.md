# 🚦 Smart Traffic & People Counter

Detects cars, motorcycles, buses, trucks and people with **YOLO26n** and counts how many cross a
line. Everything runs **in your browser** with ONNX Runtime Web: videos are never uploaded.

Source code, Python version, CPU benchmark and details:
https://github.com/amjad-c-k/traffic-people-counter

Built with [Ultralytics YOLO](https://github.com/ultralytics/ultralytics) (AGPL-3.0) and
[ONNX Runtime Web](https://onnxruntime.ai/).
Sample video: [Elevated View of Highway with Traffic](https://www.pexels.com/video/elevated-view-of-highway-with-traffic-10995755/) (Pexels, free licence).
